# LicketySync — app

The shared web UI and the Tauri 2 shells for Windows, macOS, Linux, Android
and iOS. One interface everywhere; the shell owns what the platform owns
(tray, notifications, file dialogs, safe areas), the page uses the system
font, accent colour and light or dark setting.

Today it holds the phone shell's foundation: a Tauri 2 app that shows a
one-page UI on Android and iOS and links the core crates. The shells proper come
next: desktop in phase 3, phones in phase 4. The same UI bundle becomes the
browser client published from the `web` repository.

```
ui/         the page: static HTML and one script (Leptos, built with trunk, later)
isolation/  Tauri's isolation pattern: a hook that passes only the page's command
            (defence in depth; the capability's command list is the boundary)
mobile/     the Tauri 2 mobile project; gen/android is generated by Tauri
ci/         the pins (pins.env), their check, and the APK's manifest and emulator checks
gate.sh     the checks every change passes before it is committed
```

Planned besides: `desktop/` (Tauri 2 for Windows, macOS and Linux) and `e2e/`
(Playwright tests against the UI in its shell).

The `licketysync-*` crates come in as a git dependency on the public `core`
repository, pinned by rev to the commit `ci/pins.env` names (`CORE_REV`);
`gate.sh` and CI run core's scripts and Semgrep rules from cargo's checkout of
it. Dependabot does not move it: moving `CORE_REV` is a change of its own.

Building the Android APKs needs the Android SDK and NDK, a JDK and the Tauri
command line at the versions in `ci/pins.env`:

```
cd mobile
cargo tauri android build --debug --apk --split-per-abi --target x86_64 --target aarch64
```

Gradle checks every artifact it downloads against
`mobile/gen/android/gradle/verification-metadata.xml`. Those checksums were
recorded from the first download, not from a signature; they were cross-checked
once against the repositories' own published checksum files (the CHANGELOG
says with what result).

The iOS project is generated and built on macOS only (`.github/workflows/ios.yml`).
